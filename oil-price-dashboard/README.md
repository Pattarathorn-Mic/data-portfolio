# Bangchak Oil Price Dashboard

An Excel data analysis project using real oil price data from Bangchak.  
This dashboard visualizes monthly trends, compares fuel types, and includes dynamic KPIs.

---

## 📊 Project Overview

This project demonstrates:

- Data cleaning with **Power Query**
- Date transformation (BE → AD)
- **Unpivot** to convert wide format into long format
- PivotTable + PivotChart visualization
- Slicers for dynamic filtering by fuel type
- KPI Cards (Highest Month, Lowest Month, Average Price)
- Dashboard layout & UI design

## 🚀 How to use

1. Open the Excel file  
2. Go to **Data → Refresh All** to pull updated oil prices  
3. Dashboard KPIs, charts, and slicers update automatically
